# COMPLIANCE：合规、许可、AI 标识清单

动手前、发布前，各核一次。

## 声音与形象

- [ ] 声音是本人或已授权声音，有授权记录
- [ ] 形象是 AI 生成虚构人物，或已授权形象；不使用真人脸、真人声冒充他人
- [ ] 不做名人克隆、不做变声冒充、不做未授权翻唱/原话复述

## 成片标识

- [ ] 成片带“AI 数字人演绎”标识（画面内 + 描述栏）
- [ ] 直播 / 卖货场景，标识不得只放在角落小字

## 模型与素材

- [ ] 每个模型核查日期 + 来源 + 许可证原文（权重、API 条款分开核）
- [ ] 商用前核对：是否允许商用、是否要求署名、是否限制再分发
- [ ] 第三方素材（音乐、字体、地图数据）同样核许可

## 内容

- [ ] 数字、价格、主张有来源；模型编造的数字不许上片
- [ ] 示意画面标注“示意”，不冒充真实录屏、真实场景
- [ ] 不直接复制他人组件参数与提示词模板；方法论可以学，原文不要搬

每套成片只需导出 **1 张封面 JPG＋1 条 4–6 秒 GIF＋1 条完整 MP4**，三者来自同一个完成版本，不需要为各格式重新生成。

| 优先级／题材 | 需要补的内容 | 现有材料能做什么 | 是否需要新生成 |

| P1 产品推荐 | 一个具体产品、1–2 个确认的卖点、适合谁；最好有授权商品图 | 现有测试口播可验证包装，不能充当实际产品推荐台词 | 产品题材新对白需要生成或自备录制好的原片；商品图由用户提供 |
| P1 三点干货 | 开场、三个方法与收尾，约 10 秒 | 已有「下班放松」原片已按新模板重包；本地完整有声 MP4 尚未公开 | 再验证其他主题需自备对应原片或单独批准生成 |
| P1 情感共鸣 | 一种具体处境、温和回应、一个小行动 | 现有测试口播能验证暖色配方，不能变成新的安慰表演 | 需要匹配对白的已有原片，或单独批准新生成 |

## 后续能力完成后再补

- **完整商品演示**：真实产品原片或已确认的产品台词、授权商品图／视频；商品素材布局已支持，仍缺对应产品题材样片。
- **步骤教程**：3 个真实操作步骤和对应截图／录屏；先补横屏与界面聚焦。
- **发布解读**：官方资料或演示素材；先补主播与资料分栏。
- **景深字**：有头顶与两侧留白的中景原片；先补跨平台分割与合成。
- **多主播／多语言**：分别授权的形象与准确文案，待对应流程和声音检查完善。

不要提前把这些项目放进“可用模板”卡片。完整题材视频补齐后，替换现在标注为包装预览的动图。

## 本地复现

准备文中指定的已完成测试任务，并配置本地 Vosk 中文模型后，在仓库根目录运行：

```text
python scripts/preview_library.py --job-dir PATH_TO_FIRST_PILOT --template-job-dir PATH_TO_SECOND_PILOT --output-dir outputs/library-preview --public-dir outputs/library-images --asr-model PATH_TO_VOSK_MODEL
```

两个输出目录都必须尚不存在。脚本只读取已有原片、校验哈希并本地渲染；公开文件只包含静态图和无声 GIF。先看片并确认素材授权，再决定是否将它们放入公开仓库。

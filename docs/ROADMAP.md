# ROADMAP：三期里程碑与验收标准

## 一期：换掉生成和质检（核心）

- 交付：多模型适配器 + 报价门 + 缓存 + 音频优先流程 + 五维评分 + 自动重拍 + qa.json
- 验收：固定 30 秒稿子，重拍率、唇音分、每分钟成本三项同时优于“单模型 + 人工看帧”基线
- 不做：直播、情绪多语言全量、数据回流调权

## 二期：锁定声音和情绪（差异化）

- 交付：盲测胜出 TTS 为默认音频层，情绪/语速/停顿结构化，情绪一致性进 QA
- 验收：盲听 5 种情绪至少 4 种可辨，跨段音色漂移在阈值内
- 前置条件：盲测跑完，有实测数；没跑完不许写死选型

## 三期：直播和分发（升维）

- 交付：ASR → LLM → 流式 TTS → 实时唇形 → RTMP，打断、弹幕、商品卡片，话术兜底
- 验收：端到端延迟、打断成功率、直播中断恢复时间三项有实测数
- 交付：多尺寸导出、SRT、封面 A/B、完播回流（只调包装权重，不改事实）

# QA_BENCHMARK：五维评分与 Benchmark 方法

## 固定测试集

- 同一份 30 秒稿子（3 段，每段一句话）
- 同一个主播（同一张定妆照、同一个音色 ID）
- 同一套阈值、同一种导出尺寸

改模型、改路由、改阈值，都要重跑这套测试集，再对比。

## 对比的四个数

| 指标 | 方向 | 说明 |
|---|---|---|
| 重拍率 | 越低越好 | 重拍段数 / 总段数 |
| 唇音分 / 人脸一致性 | 越高越好 | 取各段平均值与最小值，最小值更重要 |
| 每分钟成本 | 越低越好 | 含重拍成本，不含缓存命中部分要单独列 |
| 首次通过率 | 越高越好 | 一次就过线的段占比 |

## 报告格式

每次 Benchmark 输出一份带日期的报告：测试集版本、模型与参数版本、四个指标、每段五维分数、成本明细。报告进 `benchmarks/`，不要只记在聊天记录里。

## 常见作弊（不要做）

- 只挑过线的段算平均，把没过的段悄悄删掉
- 用英文 demo 证明中文唇形
- 阈值调低了就说“通过率提高了”，不提阈值变了
- 成本只算首次生成，不算重拍

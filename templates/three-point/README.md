开场点题 → 三个小方法逐项亮起 → 一句收尾。适合生活技巧、经验分享或简短教程。

## 附上照片，直接告诉助手

```text
用三点干货模板，分享三个整理桌面的小习惯。
```

助手会拟一段短台词，安排标题、三个要点、小幅景别变化和收尾重点。确认实际台词、片段和费用后才生成；首次默认约 10 秒、普通话、9:16、720p。如果某个主题需要专业事实或用户自己的信息，先补充可靠依据。

生成使用自己的 Grok Bot 账号和额度，单次消耗由服务方决定。Codex / Claude Code 自身也可能收费；本地识别和重包不调用付费生成。

## 换内容并复现

下面两份 brief 分别演示已有样片的文案和一个不同主题；它们只是助手可参考的文件，普通用户无需手填。

- [下班放松](example.json)：与上述已有原片对白一致。
- [整理桌面](example-desk.json)：另一个可替换主题。已用 Windows 本地合成语音和静态照片验证包装；真实口播仍需相应原片。

```text
dhp make plan --image presenter.png --brief-file templates/three-point/example-desk.json --output-dir outputs/my-video
dhp make show --project outputs/my-video
```

这两步只准备计划。助手把开场、三个方法与收尾保存到计划中；每个方法最多 18 字。批准后，`run` / `resume` 自动按这些结构安排本地包装。已有三点项目可用 `make restyle --project` 修改标题或风格，复用原片和原声。

单段视频若语音匹配失败，三个方法的时间按文案长度估算并显示警告；多段视频匹配失败时只保留标题。旧项目若没有保存三点结构，也只保留标题，不会从无关台词编造三个方法。所有情况都需听看成片，检查字幕、切换与口型。
